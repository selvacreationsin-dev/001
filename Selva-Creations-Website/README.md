# Selva Creations Website

This is a static website ready for GitHub Pages.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `selva-creations-logo.jpg` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

No build command or dependencies are required.

## Custom domain

After GitHub Pages publishes the site, enter `selvadesigns.in` under **Settings → Pages → Custom domain** and update the DNS records at your domain provider as GitHub instructs.
